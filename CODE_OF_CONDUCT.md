# Code of Conduct

## Our Pledge

BidBoard started as a college project, but it's open for anyone to learn from, use, or contribute to. We want that to be a positive experience for everyone, regardless of experience level, background, or how they found the repo.

## Our Standards

Examples of behavior that helps create a good environment:

- Being respectful and patient, especially with first-time contributors or students still learning
- Giving constructive feedback on code, not on people
- Accepting that this is a learning project — mistakes and rough edges are expected
- Focusing on what's best for the project and its users

Examples of unacceptable behavior:

- Insulting or derogatory comments, personal or political attacks
- Public or private harassment
- Publishing others' private information (such as email addresses used for testing) without permission
- Submitting deliberately malicious code or exploiting the security issues listed in `SECURITY.md` against real deployments

## Scope

This Code of Conduct applies within all project spaces — issues, pull requests, discussions — and in any other space where someone is representing the project.

## Enforcement

Instances of unacceptable behavior may be reported by opening an issue marked `conduct` or contacting the maintainer directly. All complaints will be reviewed and handled as fairly as possible. Maintainers reserve the right to remove comments, commits, code, issues, and other contributions that violate this Code of Conduct, and to temporarily or permanently ban contributors for behavior deemed inappropriate.
